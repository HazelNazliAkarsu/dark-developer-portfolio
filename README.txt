YOUR NAME — Premium Developer Portfolio Template

1. OPEN THE WEBSITE
Double-click index.html to open the template in a modern browser. No build tools, server, framework or installation are required.

2. CHANGE THE NAME
Search all files for "YOUR NAME". Replace it with the template owner's name. Also update "YN" in the logo, the page title, description, email address and footer.

3. CHANGE COLORS
Open style.css and edit the variables at the top of the file:
--ink = near-black background
--surface = alternate section background
--wine and --wine-bright = burgundy accents
--rose = light accent text
You can also adjust --cream and --muted for text contrast.

4. REPLACE IMAGES
The sample project artwork is intentionally CSS-generated, so the template has no copyrighted or missing image files. To use real images, add your files to assets/images/ and replace a project's .project-visual contents or background styles in index.html and style.css. Use descriptive alt text for every real image.

5. EDIT PROJECTS
Each project is an <article class="project-card"> in index.html. Duplicate an article to add another project. Change its title, category, year, description, technology tags and link. Keep the existing classes to preserve the layout and hover effects.

6. EDIT SKILLS
In the skills section, edit or duplicate <span class="skill-pill"> elements. Keep skill names short for the best responsive result.

7. EDIT SOCIAL LINKS
In the contact section, replace the placeholder LinkedIn, GitHub and Instagram URLs with the owner's URLs. Update the mailto link and visible email address as well.

8. DEPLOY
Upload index.html, style.css, script.js and the assets folder to any static host such as GitHub Pages, Netlify, Vercel or a regular web host. No server-side code is required.

9. BASIC CUSTOMIZATION
The site uses semantic HTML sections, reusable CSS classes and CSS variables. Edit content in index.html, visual styles in style.css and interactions in script.js. The mobile menu, smooth scrolling, active navigation, scroll reveal, reduced-motion support and contact form UI are already included.

SELLING NOTES
This package contains only original HTML, CSS-generated artwork and JavaScript. It does not bundle paid dependencies, analytics, personal information or third-party image assets. Replace every clearly marked placeholder before delivering a customized version to a client.
